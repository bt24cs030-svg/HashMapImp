# HashMap Implementation in Java

A custom generic `HashMap<K, V>` implementation in Java using arrays and linked lists.

## Features
- Generic key-value storage
- Collision handling using chaining
- `put()`, `get()`, `remove()`
- `containsKey()`
- `keySet()`
- `size()`

## Compile & Run

```bash
javac HashMapImp.java
java HashMapImp
